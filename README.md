AquaTimer - Software

Desarrollado por: Victoria Oszust

Descripción

Esta carpeta contiene la documentación relacionada con el software del proyecto AquaTimer, un temporizador para la ducha diseñado para fomentar el ahorro de agua y promover el cuidado del medio ambiente.

Funcionamiento

El programa utiliza una Raspberry Pi Pico para controlar un anillo NeoPixel de 12 LEDs. Al iniciar el temporizador, las luces se encienden en verde y, a medida que transcurre el tiempo, se van apagando progresivamente. Cuando el tiempo finaliza, todos los LEDs se encienden en rojo.

Herramientas utilizadas

* Wokwi: plataforma de simulación de circuitos electrónicos.
* MicroPython: lenguaje de programación utilizado para controlar el microcontrolador.
* Raspberry Pi Pico: placa encargada de ejecutar el programa.
